# النظام الشمسي — محاكاة ثلاثية الأبعاد بدقة علمية

<p dir="ltr" align="center"><b><i>Py | Sohaib Qudeih</i></b></p>

محاكاة ثلاثية الأبعاد للنظام الشمسي بـ **three.js r187** (WebGL2). المواقع حقيقية حسب التاريخ: لما تفتح الصفحة، الكواكب والأقمار بأماكنها الفعلية **هلّق**، والأرض بنهارها وليلها الحقيقيين.

---

## التشغيل

المتصفح يمنع تحميل الوحدات (ES Modules) والصور إذا فتحت `index.html` مباشرة (`file://`)، لذلك لازم سيرفر محلي بسيط:

```bash
cd solar-system
npx serve .
```
ثم افتح الرابط اللي بيظهر (عادةً <http://localhost:3000>).

بدائل:
- **VS Code**: إضافة *Live Server* ← كليك يمين على `index.html` ← *Open with Live Server*.
- **Python**: `python -m http.server 8000` ثم <http://localhost:8000>.

**الصور (اختياري لكن بيعطي أعلى واقعية):**
```bash
./download-textures.sh          # ماك/لينكس: 2K + 8K
./download-textures.sh --2k     # 2K فقط
```
```powershell
powershell -ExecutionPolicy Bypass -File .\download-textures.ps1   # ويندوز
```
تفاصيل أسماء الملفات بالضبط ومكانها: [`textures/README.md`](textures/README.md).
بدون صور المحاكاة بتشتغل عادي: كل جرم ناقصه صورة بيتولّد سطحه بالكود على كرت الشاشة.

> يحتاج اتصال إنترنت لتحميل three.js من CDN (jsDelivr) وخطوط Google. المتصفحات المدعومة: Chrome/Edge/Firefox الحديثة، Safari 15+.

## الاستخدام

| | الكمبيوتر | الموبايل |
|---|---|---|
| لف 360° حول الجرم | سحب بالماوس | سحب بإصبع |
| تقريب/إبعاد (من مدار قمر صناعي لحد النظام كله) | عجلة الماوس أو `+` / `−` | إصبعين |
| اختيار جرم | من القائمة، أو نقرة عليه أو على اسمه بالمشهد | نفس الشي (زر 🪐 يفتح القائمة) |
| الجرم التالي / السابق | `←` `↓` / `→` `↑` | — |
| تشغيل/إيقاف الزمن | `مسافة` | زر ▶ |
| منظر عام / تتبع / المقياس | `H` / `F` / `S` | أزرار الشريط العلوي |
| الأسماء / المدارات / منظر قمر صناعي | `L` / `O` / `T` | أزرار |

- **منظر قمر صناعي**: من بطاقة المعلومات، الكاميرا بتنزل لمدار منخفض (~6.5% من نصف القطر، مثل محطة الفضاء فوق الأرض)، ولما تقرّب أكثر بتميل تلقائياً نحو الأفق وبيبين الغلاف الجوي. عند الاقتراب الشديد بتظهر تفاصيل دقيقة إضافية فوق الصورة حتى ما تصير ضبابية.
- **المقياس**: *مرئي* (مسافات مضغوطة وأحجام مكبرة) أو *حقيقي* (أحجام ومسافات حقيقية تماماً)؛ الانتقال بينهم متحرك وناعم والكاميرا بتحافظ على التأطير.
- **الوقت**: حقيقي، ساعة/ث، يوم/ث، شهر/ث، سنة/ث، ورجوع للخلف، وخانة للانتقال لأي تاريخ بين سنة 1 وسنة 3000.
- **الإعدادات**: الجودة (منخفض/متوسط/عالي/فائق)، السطوع، سطوع النجوم، التوهج، الكويكبات، مدارات الأقمار، الغيوم، الإمالة نحو الأفق، عدد الإطارات.

## الدقة العلمية

| الجانب | المصدر / الطريقة | التحقق |
|---|---|---|
| مواقع الكواكب | عناصر كبلر لـ JPL (E. M. Standish): الجدول 1 (1800–2050) والجدول 2 مع حدود b,c,s,f (3000ق.م–3000م)، مدارات إهليلجية مع ميل وانحراف حقيقيين | مقارنة مع `astronomy-engine` (VSOP87): الخطأ < 1′ للكواكب الداخلية و< 10′ لزحل بين 1600 و2900 |
| الأرض | مركز ثقل الأرض-القمر ناقص إزاحة القمر (÷ 82.3) | — |
| القمر | نظرية مختصرة مع 12 حداً للطول و5 للعرض (Evection, Variation, …) | خطأ ≈ 2′ والمسافة ± 450 كم |
| أقمار المشتري | عناصر JPL المتوسطة (n من JPL) مع طور معايَر على نظرية L1.2 | خطأ < 2° |
| تيتان، تريتون، فوبوس، دايموس | عناصر JPL المتوسطة مع تقدم الحضيض وتراجع العقدة | طور تيتان مطابق لنظرية Meeus ضمن 0.8° |
| اتجاه المحاور والدوران | نماذج IAU WGCCRE (القطب RA/Dec وخط الطول الرئيسي W)، مع نموذج القمر الكامل بالـ librations | النقطة تحت الشمس على الأرض مطابقة ضمن 0.07°، واهتزاز القمر ضمن 0.05° |
| ميل المحور | ناتج من قطب IAU ومستوى المدار: الأرض 23.44°، المريخ 25.19°، زحل 26.73°، الزهرة 177.4° (عكسي)، أورانوس 97.8° (عكسي) | ✔ |
| الأرقام في البطاقات | NASA Planetary Fact Sheet | — |

> ملاحظة: الأرقام مأخوذة من NASA Planetary Fact Sheet و JPL كما هي منشورة؛ عدد الأقمار يتغير مع الاكتشافات (القيم المعروضة هي المؤكدة حتى 2025).

**تفاصيل بصرية:**
- **الأرض**: نهار + أضواء مدن **فقط بالجهة المظلمة** + غيوم بطبقة منفصلة تدور أسرع شوي + ظل الغيوم على الأرض + Normal map للتضاريس + Specular (المحيطات تلمع، اليابسة لا) + تشتت رايلي/مي للغلاف الجوي مع غروب أحمر عند خط الفصل الناعم + ميل 23.44°.
- **الشمس**: سطح متحرك (حبيبات حمل حراري + بقع شمسية + إظلام الأطراف) + كورونا + Bloom، وهي مصدر الضوء الوحيد (`PointLight`) — الـ shaders المخصصة بتقرأ موقعها ولونها وشدتها.
- **زحل**: حلقات بشفافية (C, B, قسمة كاسيني, A, فجوة إنكي) + ظل الكوكب على الحلقات + ظل الحلقات على الكوكب، مع تفلطح الكوكب الحقيقي.
- **الكسوف والخسوف**: ظلال تحليلية بين الأجرام (ظل كامل وشبه ظل)، وخسوف القمر بلون أحمر من انكسار الضوء بغلاف الأرض.
- **أورانوس ونبتون**: حلقات خافتة بأنصاف أقطارها الحقيقية + غلاف جوي. **الزهرة**: غيوم كثيفة (فيك تخفيها لتشوف السطح). **المريخ**: غلاف رقيق مائل للأحمر.
- **حزام الكويكبات**: آلاف القطع بـ `InstancedMesh` (6 أشكال)، كل وحدة بمدار كبلر حقيقي محسوب على الـ GPU، مع فجوات كيركوود.

## التقنية والأداء
- WebGL2، `logarithmicDepthBuffer` + أصل عائم (floating origin) + مستوي قريب ديناميكي ← لا وميض ولا تداخل أسطح من مستوى السطح لحد 10¹⁰ كم.
- `ACESFilmicToneMapping` + `SRGBColorSpace` للصور الملونة، و`EffectComposer` (RenderPass → UnrealBloomPass → OutputPass) مع MSAA.
- LOD للهندسة (3 مستويات حسب الحجم الظاهر) وللصور (2K ثم 8K عند الاقتراب، وتحرير 8K عند الابتعاد).
- Anisotropic filtering بأعلى قيمة يدعمها الجهاز، و`pixelRatio` بحد أقصى 2.
- عند تغيير الجودة: `dispose` للهندسة والمواد والصور المولّدة وصور 8K وإعادة بناء الكويكبات.

## التخصيص
- كل بيانات الأجرام: `js/data.js` ← `DATA`.
- كل مسارات الصور: `js/data.js` ← `TEXTURES`.
- التوقيع: `js/data.js` ← `SIGNATURE`، وبالـ `index.html` (عنصرين `data-signature`).
