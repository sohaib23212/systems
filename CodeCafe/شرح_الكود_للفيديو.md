## 2) شرح الكود قسماً قسماً

### القسم 1: General Styles
- `* { box-sizing: border-box; }`: تُحسب الـ padding والـ border داخل العرض، فلا يكبر العنصر عن العرض الذي أحدده.
- `body`: أزلت الـ margin الافتراضي، ووضعت لون الخلفية `#f7f6ef` ولون النص `#233a32`، والخط `Arial, sans-serif` بحجم `16px`، و`line-height: 1.6` لتسهيل القراءة.
- العناوين `h1, h2, h3` بلون `#17493b`، و`h1` بحجم `36px`، و`h2` بحجم `28px` كما في المطلوب.
- `img, video { max-width: 100%; }`: لا تخرج الصور والفيديو عن عرض الشاشة أبداً.
- `img { height: auto; }`: يحافظ على نسبة أبعاد الصورة.
- `hr`: أزلت الشكل الافتراضي ووضعت خطاً رفيعاً بلون الحدود `#dddddd` مع مسافة `20px`.

### القسم 2: Header and Navigation
- `header { display: flex; justify-content: space-between; align-items: center; }`: هنا استخدمت **Flexbox** لوضع الشعار والقائمة بجانب بعض؛ الشعار يسار والقائمة يمين، ومحاذاتهما عمودياً في المنتصف.
- خلفية الهيدر `#143d32`.
- `header img { width: 150px; }`: عرض الشعار 150px حسب المطلوب.
- `nav ul { display: flex; gap: 10px; list-style: none; }`: الروابط بجانب بعض بمسافة 10px، وأزلت النقاط.
- `nav a`: حوّلت الروابط إلى **أزرار**: `display: block` و`padding` وخلفية `#245b49` ونص أبيض بدون خط سفلي و`border-radius`.
- `nav a:hover`: عند مرور الماوس تتغير الخلفية إلى `#e5b96d` (لون الـ highlight) ويصبح النص داكناً. **(اعرضها في المتصفح)**

### القسم 3: Main Content
- `main { max-width: 1080px; margin: 0 auto; }`: أقصى عرض للمحتوى 1080px، و`margin: 0 auto` تضعه في منتصف الصفحة.

### القسم 4: Hero Section
- خلفية `#e6efe7`، وحدّ خفيف، و`border-radius: 12px`، و`padding: 40px`، و`text-align: center` لتوسيط المحتوى.
- `list-style-position: inside`: تبقى نقاط القائمة مع النص في المنتصف.
- صورة الهيرو `width: 440px` كما في المطلوب، مع `display: block; margin: auto` لتوسيطها.

### القسم 5: Story Section
- بطاقة بخلفية بيضاء `#ffffff` وحدّ `#dddddd` وزوايا دائرية و`padding`.

### القسم 6: Menu Section
- `#menu { display: flex; flex-wrap: wrap; justify-content: center; gap: 25px; }`: Flexbox مع `flex-wrap` حتى تظهر البطاقات الثلاث بجانب بعض، وتنزل لسطر جديد عند الحاجة.
- `#menu > h2, #menu > p { width: 100%; }`: العنوان والوصف ورابط الحجز يأخذ كل منها سطراً كاملاً. الرمز `>` يعني الأبناء المباشرين فقط، فلا يتأثر الـ `p` الموجود داخل البطاقات.
- `#menu article`: كل بطاقة عرضها `29%`، بخلفية بيضاء وحدّ وزوايا دائرية و`padding`، والنص داخلها لليسار.
- صورة البطاقة `width: 100%` لتملأ عرض البطاقة.
- `#menu article strong`: السعر بلون `#9a5b26`.

### القسم 7: Gallery Section
- نفس فكرة المنيو: `display: flex` و`flex-wrap` و`gap`، والصورتان بجانب بعض.
- كل `figure` عرضه `43%`، بخلفية بيضاء وحدّ وزوايا دائرية.
- `figcaption`: نص مائل `italic` في المنتصف ولونه رمادي.

### القسم 8: Visit Us Section
- بطاقة بيضاء بحدّ وزوايا دائرية.
- `address { font-style: normal; }`: العنوان يظهر مائلاً افتراضياً، فجعلته عادياً.

### القسم 9: Table Styling
- `width: 100%` و`border-collapse: collapse`: تندمج حدود الخلايا في خط واحد بدل الخطوط المزدوجة.
- `th, td`: حدود واضحة و`padding: 10px`.
- `th`: **رأس الجدول ملوّن** بخلفية `#17493b` ونص أبيض.
- `tbody tr:nth-child(even)`: خلفية فاتحة للصفوف الزوجية لتسهيل القراءة.

### القسم 10: Aside Section
- خلفية مختلفة `#e7efe8`، وحدّ أيسر ملوّن `border-left: 5px solid` يميّزها كنصيحة.

### القسم 11: Media Section
- `text-align: center` للعنوان والنص.
- `video { display: block; width: 500px; margin: 0 auto; }`: الفيديو في المنتصف، ومع `max-width: 100%` من القسم الأول لا يتجاوز عرض الصفحة أبداً.

### القسم 12: Footer
- خلفية داكنة `#143d32` ونص أبيض واضح، وكل شيء في المنتصف.
- رابط "Back to top" بلون ذهبي `#e5b96d` ليظهر على الخلفية الداكنة.

### القسم 13: Responsive Design
- `@media screen and (max-width: 700px)`: **media query واحدة** للشاشات حتى 700px.
- `header { flex-direction: column; }`: الشعار والقائمة فوق بعض.
- `nav ul { justify-content: center; }`: الأزرار في المنتصف، وتلتف لسطر جديد بفضل `flex-wrap`.
- تصغير الخطوط: `h1` إلى `26px` و`h2` إلى `22px`، وتقليل الـ padding والمسافات.
- `#menu article, #gallery figure { width: 100%; }`: البطاقات والصور في **عمود واحد**.
- الصور والفيديو لا تخرج عن الشاشة بسبب `max-width: 100%`.

## 3) العرض في المتصفح (2–3 دقائق)
1. افتح `index.html` بالمتصفح ومرّ على الصفحة من الأعلى للأسفل.
2. مرّر الماوس على أزرار القائمة لتظهر تأثير الـ **hover**.
3. اضغط على رابط مثل "Menu" لينتقل للقسم، ثم "Back to top".
4. شغّل الفيديو.
5. **التجاوب:** اضغط `F12` ثم أيقونة الموبايل (Toggle device toolbar) أو `Ctrl+Shift+M`، واختر جهازاً مثل iPhone، أو صغّر عرض النافذة تحت 700px، ووضّح أن:
   - الهيدر صار عمودياً.
   - البطاقات والصور صارت في عمود واحد.
   - الخطوط والمسافات أصغر.
   - الصور والفيديو داخل حدود الشاشة.
