# فحص الواجهة في متصفح حقيقي

يفتح كل صفحة في النظام ولوحة المسؤول، مع كل تصميم جاهز، على مقاسات الهاتف واللوحي والحاسوب،
ويقيس ما رسمه المتصفح فعلاً:

| النوع | المعنى |
|---|---|
| `hscroll` | الصفحة أعرض من الشاشة (تمرير أفقي، وانزياح القائمة والشريط السفلي على الهاتف) |
| `offscreen` | عنصر يخرج عن حدود الشاشة |
| `overlap` | نصّان أو أداتان تتراكبان ويُريان معاً (قطع الرسم التوضيحي الواحد داخل `aria-hidden="true"` تتراكب عمداً فلا تُحتسب فيما بينها، وكذلك صور مربعات الخريطة تحت علاماتها) |
| `spill` | نص يخرج عن صندوقه |
| `contrast` | نص تباينه أقل من 3:1 (يُقاس على البكسلات عند الخلفيات المتدرّجة) |
| `blocked-tap` | زر لا يمكن الضغط عليه لأن عنصراً آخر يغطيه |
| `drawer` / `dropdown` | القائمة الجانبية أو المنسدلة خارج الشاشة أو في غير مكانها |
| `footer-*` | الشريط السفلي يغطي آخر المحتوى أو بغير عرضه الصحيح |
| `jserror` / `http` / `php` | أخطاء JavaScript، أو طلبات فاشلة، أو أخطاء PHP في الصفحة |

التصميم يُبدَّل من صفحة «التصاميم» في لوحة المسؤول كما يفعل المسؤول.

## التشغيل

يحتاج Node.js و Playwright (Chromium)، ونسخة تعمل من النظام (لا تشغّله على نظام حقيقي لأنه يبدّل التصميم).

```
node tests/ui/run.js --base=http://127.0.0.1:8080 --slug=اسم-الحساب --user=U --pass=P --admin-user=A --admin-pass=B
```

خيارات: `--designs=all|current|nexus,aurora` · `--widths=320,360,412,768,1280` · `--langs=ar,en` · `--schemes=light,dark` ·
`--combos=ar:light,en:dark` · `--extra=/الحساب/cards/1,/الحساب/search?q=a` (صفحات لا تصلها الروابط) ·
`--public=/,/login,…` (صفحات بلا دخول) · `--only=/cards,/admin/design` · `--concurrency=4` · `--out=report.json` · `--no-contrast`

تُفتح كل نافذة منبثقة (dialog) في كل صفحة وتُفحص وحدها، وتُفحص القائمة الجانبية والقوائم المنسدلة في الشريط العلوي.

رمز الخروج 0 فقط عندما لا تُكتشف أي مشكلة؛ التفاصيل في `report.json`.

## فحوص أخرى

- `node tests/ui/flows.js --slug=… --user=… --pass=…` تفاعل حقيقي على الهاتف (320/360/412): فتح `/اسم-الحساب`، القائمة الجانبية، البحث، المظهر واللغة من قائمة الحساب، الشريط السفلي مع لوحة المفاتيح.
- `node tests/ui/preview.js --admin-user=… --admin-pass=… --presets-file=…` معاينة كل تصميم في صفحة «التصاميم».
- `node tests/ui/landing.js --admin-user=… --admin-pass=…` صفحة الهبوط بتفاعل حقيقي: تبويبات الجولة ولقطاتها ولوحة المفاتيح، العرض بلا JavaScript، إبراز القسم الظاهر وشريط التقدّم وزر العودة للأعلى، عدّ الأرقام، والتبديل بين التصميم الجديد والكلاسيكي من لوحة المسؤول، وفيديو العرض حتى إغلاق نافذته (ينتهي على التصميم الجديد وبلا فيديو).
- `node tests/ui/hotspot.js` صفحات الهوتسبوت (`hotspot/madix-net`) بالوضعين على كل المقاسات.

كل نتيجة تباين تُثبَّت على البكسلات الفعلية، وتراكب نصّين لا يُحتسب إلا إذا تلامست حروفهما فعلاً (`verify.js`).
