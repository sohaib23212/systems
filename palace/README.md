# القصر — مصمم الغرف ثلاثي الأبعاد

**The Palace** — قصر عربي أندلسي واقعي تتجوّل داخله بنفسك وتصمّمه كما تريد: تضع الأثاث، تغيّر الخامات والألوان، وتتحكم بالإضاءة والوقت من الشروق إلى الليل.

## التشغيل

المشروع صفحة ويب ثابتة (بدون تثبيت أو بناء)، لكنه يحتاج خادماً محلياً لأن المتصفح يمنع تحميل الوحدات من `file://`:

```bash
cd palace
npx serve .
# أو
python -m http.server 8000
```

ثم افتح العنوان الظاهر (مثل `http://localhost:3000`) في Chrome أو Edge أو Firefox أو Safari 15+.

يحتاج اتصالاً بالإنترنت أول مرة لتحميل three.js والخطوط من CDN.

## التحكم

### التجوّل
| الأمر | الفعل |
|---|---|
| `W` `A` `S` `D` / الأسهم | المشي |
| `Shift` | الركض |
| سحب الفأرة / الإصبع | النظر حولك |
| `Q` / `E` | الالتفات |
| `1` … `8` | الانتقال لغرفة |
| الموبايل | عصا تحكم أسفل اليسار + اسحب في أي مكان للنظر |

الأبواب تُفتح وحدها عند اقترابك، والتصادم حقيقي مع الجدران والأثاث.

### التصميم
| الأمر | الفعل |
|---|---|
| `Tab` | وضع التصميم: منظر علوي بدون أسقف |
| النقر على قطعة | اختيارها (إطار ذهبي)، ثم اسحبها لتحريكها |
| `R` / `Shift+R` | تدوير 15° |
| `Delete` | حذف |
| `Ctrl+D` | نسخ |
| `Ctrl+Z` | تراجع |
| النقر على جدار / أرضية / سقف | تغيير خامته ولونه للغرفة كاملة |
| `F` | كتالوج الأثاث (صور مصغّرة حقيقية لكل قطعة) |
| `L` | الإضاءة والوقت |
| `P` | لقطة شاشة مع التوقيع |

القطع الجدارية (لوحات، مرايا، شمعدانات) تلتصق بالجدار. الثريات تتعلّق بالسقف. المزهريات والمصابيح توضع فوق الطاولات.

## الواقعية — كيف تعمل

- **خامات PBR مولَّدة على كرت الشاشة**: رخام (كرارا، ماركينا، فيردي، كريما) ببلاطات 80 سم وفواصل دقيقة وعروق متعرّجة تختلف من بلاطة لأخرى، باركيه شيفرون، زليج أندلسي بنجمة ثمانية، جبس عربي محفور، ورق جدران دمشقي، مخمل، كتان، جلد، سجاد فارسي، خشب، معادن. لكل خامة ثلاث خرائط: اللون، والنتوءات (normal)، والخشونة مع الإطباق المحيطي (ORM)، كلها متكررة بلا حواف ظاهرة وبمقياس حقيقي بالمتر.
- **انعكاسات حقيقية** على الأرضيات الرخامية اللامعة وعلى الماء (مرآة مستوية مع تمويه حسب خشونة السطح).
- **إضاءة غير مباشرة لكل غرفة**: مجسّات بيئة (Cube Probes) تلتقط الغرفة نفسها، فيكتسب الذهب والرخام انعكاسات المكان الحقيقي، مع ارتداد ضوئي.
- **شمس حقيقية حسب الوقت** بظلال ناعمة، وسماء فيزيائية بغيوم، وقمر ونجوم ليلاً. ضوء الشمس يدخل من الأقواس والنوافذ والمشربيات.
- **ثريات ومصابيح بإضاءة حقيقية** (تلقائي حسب الوقت، تشغيل، إطفاء)، مع تحكم بالشدة وحرارة اللون بالكلفن.
- **ما بعد المعالجة**: ظلال التلامس (GTAO)، وتوهّج الأضواء (Bloom)، وتدرّج ألوان سينمائي (AgX).
- **حركة حية**: نوافير ماء، ماء متموّج، نار المدفأة، دخان البخور، أبواب تُفتح.

## الحفظ والمشاركة

- يُحفظ التصميم تلقائياً في المتصفح بعد كل تعديل.
- **تصدير JSON**: ملف فيه الأثاث والخامات والألوان والإضاءة، تقدر ترسله لأي شخص.
- **استيراد**: افتح ملف تصميم محفوظ.
- **إعادة التصميم الأصلي**: يرجع القصر كما كان (ويمكنك التراجع).

## الجودة والأداء

من ⚙ الإعدادات:

| الجودة | الاستخدام |
|---|---|
| منخفض | الموبايل والأجهزة الضعيفة |
| متوسط | لابتوب عادي |
| عالي | كرت شاشة جيد (الافتراضي على الكمبيوتر) |
| فائق | كرت شاشة قوي: خامات أدق، وظلال 4K، وانعكاسات أوضح |

تقدر تطفئ الانعكاسات أو ظلال التلامس أو التوهّج كلٌّ على حدة.

### الكمبيوتر والموبايل
- **الكمبيوتر**: الجودة "عالي" افتراضياً، تحكّم بالفأرة ولوحة المفاتيح.
- **الموبايل والتابلت**: الجودة "منخفض" افتراضياً، عصا تحكم للمشي، سحب بالإصبع للنظر، إصبعين للتقريب في وضع التصميم، واللوحات تظهر من الأسفل.
- **ضبط تلقائي**: إذا كان الجهاز أضعف من الجودة المختارة، تُخفَّف المؤثرات تدريجياً بدون إعادة تحميل حتى تصبح الحركة سلسة.
- **تكيّف العين**: عند دخول الغرف نهاراً يرتفع التعريض تدريجياً (كما تفعل العين والكاميرا)، وينخفض عند الخروج للشمس.

## الملفات

```
palace/
├── index.html
├── css/style.css
└── js/
    ├── config.js        الغرف، الجدران، الفتحات، الكتالوج، الترتيب الافتراضي
    ├── textures.js      مولّد الخامات الإجرائية على GPU
    ├── materials.js     مكتبة المواد PBR + حقن الانعكاسات
    ├── geom.js          أدوات الأشكال (أقواس، UV بالمتر، دمج)
    ├── architecture.js  بناء القصر: جدران، أقواس، قبة، فناء، حدائق
    ├── furniture.js     كل قطع الأثاث
    ├── environment.js   الشمس، السماء، الوقت، المجسّات، الانعكاس
    ├── player.js        المشي والتصادم ووضع التصميم
    ├── editor.js        الاختيار والسحب والتدوير والحفظ والتراجع
    ├── ui.js            الواجهة العربية
    └── main.js          التشغيل وما بعد المعالجة
```

مبني بـ [three.js](https://threejs.org) r187 بدون أي ملفات صور أو نماذج خارجية: كل شيء مولّد بالكود.
