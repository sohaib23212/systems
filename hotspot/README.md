# صفحات هوتسبوت Madix Net

صفحات هوتسبوت عربية لأجهزة MikroTik، مربوطة بنظام Madix عبر مكتبة `sohaibnet.js`.

## الصفحات

| الملف | متى تظهر |
|---|---|
| `login.html` | صفحة الدخول: اسم المستخدم وكلمة المرور، الدخول المجاني (إن كان مفعّلاً)، الأسعار، نقاط البيع |
| `alogin.html` | بعد نجاح الدخول، ثم تحويل تلقائي |
| `status.html` | حالة الاتصال: الوقت المتبقي، مدة الاتصال، التحميل والرفع، IP و MAC، وتفاصيل الباقة من النظام |
| `logout.html` | بعد الخروج، مع ملخص الجلسة ثم العودة لصفحة الدخول |
| `error.html` | تنبيهات جهاز MikroTik |
| `errors.txt` | ترجمة عربية لرسائل أخطاء MikroTik |

ملفات MikroTik الأخرى (`redirect.html` و `rlogin.html` و `md5.js` و `api.json` و `xml/`) تبقى كما هي ولا تُستبدل.

## الدخول

- يكتب الزبون اسم المستخدم وكلمة المرور.
- الحساب المنشأ في النظام **باسم مستخدم فقط** يدخل بدون كلمة مرور (اتركها فارغة).
- إذا كان الكرت يحتاج كلمة مرور ولم تُكتب، تظهر رسالة النظام ويتحدد حقل كلمة المرور.
- إذا تعذّر الوصول إلى Madix، يدخل الزبون مباشرة عبر جهاز MikroTik (حسب إعداد الدخول الاحتياطي في النظام).

## الإعدادات

كل ما يتعدّل موجود في `madix-net/madix-config.js`: الاسم، الوصف، شريط الإعلانات، نقاط البيع، النصيحة، ثواني التحويل، والمظهر الليلي.
رقم الهاتف وواتساب والأسعار تأتي تلقائياً من نظام Madix.

## التنصيب على جهاز MikroTik

1. انشر ملفات الربط من Madix أولاً (ربط الهوتسبوت ← نشر الملفات)، حتى يكون `sn-config.js` و `sohaibnet.js` على الجهاز.
2. اعمل رمز GitHub للقراءة فقط على هذا المستودع (Fine-grained token ← Contents: Read-only).
3. افتح `install-madix-net.rsc`، ضع الرمز مكان `PASTE_TOKEN_HERE`، والصق الكتلة كاملة في Terminal جهاز MikroTik.
4. إذا كان مجلد الهوتسبوت عندك غير `hotspot` (مثلاً `flash/hotspot`)، عدّل قيمة `dir` في السكربت. تعرفه من `/ip hotspot profile print`.
5. احذف الرمز من GitHub بعد الانتهاء.

## المعاينة

افتح الصفحات في أي متصفح خارج الراوتر: تعمل تلقائياً في وضع المعاينة ببيانات توضيحية، مع شريط سفلي للتنقل بين الصفحات.
اسم المستخدم `0` في المعاينة يعرض شكل رسالة الخطأ.

## ملاحظات تقنية

- لا تكتب علامة الدولار متبوعة بقوس داخل ملفات JS و CSS، لأن جهاز MikroTik يعتبرها متغيراً في الصفحات.
- الخط (Readex Pro) والشعار مضمّنان في المجلد، فالصفحات لا تحتاج إنترنت قبل الدخول.
- الكود بصيغة ES5 ليعمل على المتصفحات القديمة.
